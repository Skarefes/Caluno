# Caluno

O **Caluno** é uma aplicação voltada para o registro e acompanhamento do consumo alimentar.

A proposta do projeto é facilitar o acompanhamento nutricional de forma simples, permitindo que o usuário registre alimentos e suas respectivas quantidades e obtenha automaticamente informações nutricionais proporcionais ao consumo.

## Objetivo

O projeto busca tornar o acompanhamento da alimentação mais simples e acessível, reduzindo a necessidade de realizar manualmente cálculos de calorias e outros nutrientes.

## Funcionalidades

* Cadastro e consulta de alimentos;
* Consulta de informações nutricionais;
* Registro do consumo de alimentos;
* Integração com dados nutricionais da **USDA FoodData Central**;
* Organização das informações nutricionais em uma estrutura própria da aplicação.
* Desenvolvimento de API REST utilizando Java e Spring Boot.
* Cadastro e gerenciamento de usuários.
* Persistência de dados utilizando PostgreSQL e mapeamento objeto-relacional com JPA/Hibernate.
* Gerenciamento e versionamento do banco de dados com Flyway.
* Cálculo e apresentação de informações nutricionais
* Desenvolvimento de interface web utilizando HTML, CSS e JavaScript, integrada ao backend.
* Tradução de ingles para portugues e vice versa usando Mymemory

Entre os nutrientes trabalhados estão:

* Calorias;
* Proteínas;
* Carboidratos;
* Gorduras;
* Fibras;
* Sódio.

## Tecnologias

* Java
* Spring Boot
* Spring Data JPA
* PostgreSQL
* Flyway
* REST API
* USDA FoodData Central API
* MyMemory

## Objetivo acadêmico

O Caluno também faz parte de um projeto de extensão universitária relacionado ao **ODS 3 — Saúde e Bem-Estar**, com foco no desenvolvimento de uma solução tecnológica para facilitar o acompanhamento do consumo alimentar.
